2. Click **File -> Open Folder...**
3. Navigate to `C:\Users\kushm\.gemini\antigravity\scratch\kushmittal-portfolio` and click **Select Folder**.

## ⚡ How to Preview Live Changes in VS Code

1. Install the **Live Server** extension (by Ritwick Dey) or **Live Preview** extension (by Microsoft) in VS Code.
2. Right-click `index.html` and select **Open with Live Server**.
3. Any edits you save in `index.html`, `style.css`, or `app.js` will automatically reflect in your browser in real-time!
